# Security Policy

## Supported Versions

Security and safety fixes are accepted against the default branch.

## Reporting

Please report sensitive issues privately through GitHub Security Advisories if the repository is public and advisories are enabled. If advisories are not enabled, contact the maintainer privately.

Do not open public issues that include:

- Bypass techniques
- Exploit instructions
- Private symbols, dumps, logs, or proprietary data
- Instructions for unauthorized use in third-party online games

## Project Boundary

This project does not accept anti-cheat bypass, stealth, evasion, anti-debug bypass, protected-file decryption, or networked cheating contributions.
